Stakeholder talking points

What to say out loud

  1. Zero Go code — only a Karta CR; KubeRay is unchanged.
  2. Layer separation — Karta parses; Grove/KAI remain optional consumers.
  3. Roadmap — new AI frameworks = new maps, not dedicated Go operators.

Takeaways

What to remember

  1. Karta is the portable contract between compound CRDs and platform layers.
  2. Ray onboarding demonstrated with YAML only — no KAI/Grove required.
  3. Sibling karta-kueue-admission adds the GPU quota / admit-vs-queue story on RayJob.

New framework → new Karta map — not a new Go bridge.
